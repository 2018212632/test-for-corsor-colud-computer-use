## 工具层面能力

Agent 拥有 5 类文件操作专属工具：

- `Read` — 读文件（支持行号偏移/分段读取、图片/PDF）
- `Write` — 写/覆盖文件
- `StrReplace` — 精确字符串替换（支持 replace_all）
- `Delete` — 删除文件
- `Glob` — 按 glob 模式查找文件

## 结论

文件操作能力完整，性能极高（SSD IO ~1.6 GB/s）。
工具层面专门设计了安全的精确替换，避免了直接 sed/awk 操作的风险。
